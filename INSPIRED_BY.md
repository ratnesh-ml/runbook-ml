# Inspired by, not copied from

Runbook ML is a clean-room educational implementation of experiment
tracking, artifact lineage, run comparison, and model promotion gates. Its
product direction is informed by [MLflow](https://github.com/mlflow/mlflow),
Apache-2.0, whose public project describes experiment tracking, evaluation,
monitoring, and model lifecycle workflows.

No MLflow source code, branding, UI assets, or proprietary data were copied.
The implementation is intentionally smaller and is released under the MIT
License.
